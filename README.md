# CRAFTD website

This is a single-file, GitHub Pages-ready website. `index.html` contains the full design, responsive styling, and interactions.

## Publish it with GitHub Pages

1. Create a new GitHub repository, for example `craftd-studio`.
2. Upload the contents of this folder — especially `index.html` — to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will publish the site at `https://YOUR-USERNAME.github.io/craftd-studio/`.

## Before launch

- Replace `hello@craftd.studio` in `index.html` with the real studio email address. The project brief modal uses this address to prepare a structured email.
- Replace the demo portfolio names and placeholder copy with real campus projects.
- For a live, stored form instead of an email-based brief, connect the form to a provider such as Formspree, Netlify Forms, or your own backend.

No build tools or server are required for the current version.
